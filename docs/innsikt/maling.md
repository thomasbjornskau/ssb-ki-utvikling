# Hva vi måler

<p class="ingress">Et forslag til hva som kan følges med på, og hvor tallene kan komme fra. Vi starter enkelt, uten dashbord.</p>

| Hva | Kilde | Hvor ofte | Status |
|---|---|---|---|
| Antall lisenser og aktive brukere | Administrasjonsdata fra leverandørene | Månedlig | <span class="status avklares">Avklares</span> |
| Kostnad | Lisens- og forbruksdata | Kvartalsvis | <span class="status avklares">Avklares</span> |
| Repoer med instruksjoner eller skills | Søk i statisticsnorway på GitHub | Kvartalsvis | <span class="status forslag">Forslag</span> |
| KI-anvendelser og risikoklasse | Kartleggingen etter KI-forordningen | Halvårlig | <span class="status finnes">Pågår</span> |
| Erfaring og behov | Kort spørreundersøkelse | Halvårlig | <span class="status forslag">Forslag</span> |
| Spørsmål og avvik | Henvendelser til gruppen, avviksmeldinger | Løpende | <span class="status forslag">Forslag</span> |

## Det vi ikke måler

Vi måler ikke enkeltpersoners bruk, og vi bruker ikke tallene til å vurdere enkeltpersoner. Tall per team vises bare når teamet er stort nok til at ingen kan identifiseres. Det er det samme prinsippet vi bruker i statistikken vår.
